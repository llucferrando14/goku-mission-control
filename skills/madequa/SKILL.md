### Phase 1: Design
1. Identify opportunity
2. Form hypothesis
3. Define metrics (baseline → target)
4. Plan implementation

### Phase 2: Run
1. Implement experiment
2. Monitor closely
3. Document everything

### Phase 3: Analyze
1. Collect results
2. Compare to hypothesis
3. Extract learnings

1. Write repeatable process
