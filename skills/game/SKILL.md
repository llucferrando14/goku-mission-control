# Game Development Skill

## Project Overview

**Engine:** Unity  
**Platform:** Mobile (Android — Google Play Store)  
**Deadline:** May 31, 2026  
**Status:** Concept Phase  
**Time Budget:** ~10 hours/week  

---

## Core Constraints

- **Solo development** — no team, all decisions on you
- **Limited art skills** — strength is programming/AI, not 3D modeling
- **Dermatomyositis management** — scope must be manageable without crunch
- **10-week timeline** — concept to published game

---

## Success Criteria

### Technical
- [ ] Core mechanic implemented and polished
- [ ] Mobile-optimized (60fps on mid-tier devices)
- [ ] In-game advertisements integrated
- [ ] Published to Google Play Store

### Design
- [ ] Unique concept (not generic clone)
- [ ] Demonstrates design thinking (intentional mechanics)
- [ ] Polished presentation (juice, feedback, feel)

### Academic
- [ ] Defensible scope (professor can see reasonable timeline)
- [ ] Documentation (design doc, postmortem)
- [ ] Version control (Git throughout)

---

## Scope Guidelines

### ✅ Feasible in 10 Weeks
- 2D game (manageable art requirements)
- Single core mechanic (depth over breadth)
- Procedural/algorithmic content (infinite replayability)
- Physics-based or turn-based (no complex AI)

### ❌ Too Ambitious
- Multiplayer real-time
- 3D exploration
- Narrative-heavy branching
- Complex AI opponents

---

## Development Phases

### Phase 1: Foundation (Weeks 1-2)
- [ ] Concept finalization
- [ ] Technical architecture
- [ ] Core mechanic prototype
- [ ] Basic movement/interaction

### Phase 2: Core Systems (Weeks 3-5)
- [ ] Game loop complete
- [ ] Scoring/progression
- [ ] Juice and polish pass
- [ ] First playable

### Phase 3: Content & Polish (Weeks 6-8)
- [ ] Procedural generation (if applicable)
- [ ] UI/UX implementation
- [ ] Audio integration
- [ ] Ad SDK integration

### Phase 4: Launch Prep (Weeks 9-10)
- [ ] Testing and bug fixes
- [ ] Play Store setup
- [ ] Screenshots, description
- [ ] Submit and publish

### Phase 5: Buffer (Weeks 11-12)
- [ ] Emergency fixes only
- [ ] Do not touch unless critical
