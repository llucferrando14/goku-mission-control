## CONFIDENCE LEVELS EXPLAINED

**High Confidence:**
- Pattern observed 3+ times
- Lluc explicitly confirmed
- No contradictory data
- Safe to act on this pattern

**Medium Confidence:**
- Pattern observed 2 times
- Seems consistent but limited data
- Act on it but watch for contradictions
- Adjust if proven wrong

**Low Confidence:**
- Pattern observed once
- Might be coincidence
- Need more data before acting
- Log but don't rely on yet

## PATTERN EXTRACTION PROCESS

**How lessons get added to this file:**

1. **Trigger Event:**
   - Lluc explicitly corrects something
   - Same situation occurs 2+ times
   - Pattern observed across domains
   - Something unexpectedly worked or failed

2. **Analysis:**
   - What was the context?
   - What actually happened?
   - Why did it happen?
   - Is this repeatable?

3. **Documentation:**
   - Add to LESSONS.md with full template
   - Tag confidence level
   - Set status to Active
   - Reference in relevant skill files if applicable

4. **Application:**
   - Adjust behavior immediately
   - Watch for contradictions
   - Update confidence as more data comes in

5. **Review:**
   - Monthly: Review all lessons
   - Increase confidence if pattern holds
   - Supersede if better understanding emerges
   - Deprecate if no longer relevant
